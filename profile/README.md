# FullCircle

Tools for AI-assisted game development: Claude Code workflow, Unity and 3D animation pipelines.

## Public projects

- **[ContactDots](https://github.com/FullCircle-0/ContactDots)**: a Claude skill that measures, in millimetres and degrees on the real meshes, whether the things in an animation that should touch, sit, stay or line up really do (FBX or `.blend`, Blender headless). It measures only and never changes your files.
